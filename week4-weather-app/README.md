# 🌤 Weather App

A responsive weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city
- Dummy weather data (No API required)
- Temperature Unit Conversion (°C / °F)
- 5-Day Forecast
- Favorite Cities
- LocalStorage Support
- Responsive Design
- Loading State
- Error Handling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
