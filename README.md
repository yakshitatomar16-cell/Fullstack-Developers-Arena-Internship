# E-Commerce Backend

## Project Description
This is a simple E-Commerce Backend application developed using Spring Boot and PostgreSQL.

### Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven

### Project Structure
- Entity
- Repository
- Service
- Controller
- DTO
- Exception
- Enums

### Features
- User Management
- Product Management
- Order Management
- Payment Management

### Note
This project is a simplified implementation of an E-Commerce Backend.

Due to system limitations and time constraints, some advanced features such as Spring Security, caching, auditing, connection pool tuning (HikariCP), complex transaction management, query optimization, and extensive testing were not fully implemented.

However, the core backend architecture (Entities, Repositories, Services, Controllers, PostgreSQL integration, and Flyway migrations) has been implemented successfully.
